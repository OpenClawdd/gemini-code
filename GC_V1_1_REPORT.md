# GC v1.1 implementation Report: The Refined Nervous System

## 1. Summary of Upgrades

GC v1.1 evolves the "nervous system" implemented in v1.0 into a coherent,
professional experience. The agent now communicates its intent and activity with
much higher fidelity and lower noise.

## 2. Completed Features

### 📡 Autopilot Event Timeline v1

- **Enhanced Data**: Event history now supports filtering (latest denied, latest
  suppressed, etc.).
- **Cockpit Integration**: The cockpit compact view displays the **[LATEST]**
  activity, while the expanded view shows the last 5 events.
- **Auto-Acknowledgement**: Safe commands (ALLOW) are recorded and acknowledged
  without ceremony.

### 🤖 Pollux (Buddy) v1

- **Event-Driven Reactions**: Buddy now reacts instantly to Autopilot decisions
  with specific, useful messages.
- **Spam Prevention**: Implemented a cooldown and deduplication mechanism to
  prevent message repetition.
- **New Commands**:
  - `/buddy status`: Summary of current mood, message, and latest event.
  - `/buddy quiet`: Minimizes feedback for focused work.

### 🏛️ Subagent Registry & Model Council v1

- **Role Lanes**: Planning now uses role-based lanes (Scout, Architect, Surgeon,
  etc.) with explicit justifications.
- **Confidence Scoring**: Each mission plan includes an overall confidence
  percentage and per-lane justifications.
- **UI Evolution**: Lanes are displayed cleanly in the cockpit compact view
  (`Lanes: scout · surgeon · test-captain`).

### ⚙️ Customization Basics

- **In-Memory Settings**: `GcSettings` allows steering UI preferences
  (verbosity, expansion).
- **Default Safety**: All new features remain opt-in or strictly non-intrusive
  by default.
